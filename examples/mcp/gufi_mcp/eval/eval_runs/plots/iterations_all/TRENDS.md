# Cross-iteration trends

Generated by `analyze_iterations.py` into this folder. User-facing tool trials
(`gufi_find`, `gufi_ls`, `gufi_stats`, `gufi_du`, `gufi_stat`) are excluded from
graded pass rates. General runs use soft final-text grading; single runs use
exact row match — compare within mode, not across.

## Did later iterations improve correctness?

**Single-mode (exact match), apples-to-apples:**

| Iteration | Change | Pass | One-shot |
|---|---|---|---|
| S0 `90fa7d` | first single suite | 35% | 0% |
| S1 `28ac34` | baseline / new grading + retries | 45% | 35% |
| S2 `c3e789` | histogram template in primer | 43% | 33% |
| S3 `f2769d` | UDF column hints | **53%** | **43%** |
| S4 `886bc0` | UDF primer lines | 45% | 42% |
| S5 `39600c` | expanded column tags | 42% | 32% |

- **S3 (UDF column hints) is the best single-mode design** so far.
- Histogram template (S2), primer UDF lines (S4), and longer column tags (S5)
  did **not** beat S3; S4/S5 mostly moved flaky scenarios around.
- `bytecat` never appears in graded SQL; size/age histograms stay at 0%.

**General-mode (soft match, UF tools discounted):** pass rose from ~40% (G1/G2)
to 50% (G3) to **72%** (G4). That jump is real on several mirrored prompts, but
soft grading can credit answers that fail exact single-mode checks
(`total_file_size` is 100% soft in G4 and 0% exact in every single run).

## Which prompts stay hard?

Consistently worst across every iteration (see `03_hard_scenarios.png`):

1. **`age_histogram`** — 0% everywhere
2. **`size_histogram`** — 0% everywhere (groups raw `size` → truncated)
3. **`not_modified_n_days`**, **`count_and_size`**, **`total_file_size`** — near-zero in single mode
4. **`top10_size_per_uid`** — chronically weak; never solved in general either

Reliably easy: **`top10_size_global`**, **`oldest_k`**, **`count_over_1gib`**.

Improved by design work: **`ext_winner`**, **`ext_histogram`**, **`total_dir_size`**
(especially once column/path hints landed).

## What worked / what didn’t

| Change | Effect |
|---|---|
| Path-column / aggregate cleanup (general G3→G4) | Large soft-pass gain; fewer path/sname errors |
| UDF column hints (S3) | Best exact pass (+8 pt vs baseline) |
| Histogram primer template (S2) | No overall gain; histograms still fail |
| Primer “read gufi://functions” lines (S4) | Agent still does not read that resource |
| Longer / more column tags (S5) | No gain; flaky scenario noise |
